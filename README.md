# Linux System Information & Monitoring Tool

## Project Objective
Develop a Linux command-line application using C++ that collects and displays important system information from a Linux system. This project is built progressively in a beginner-friendly way, demonstrating fundamental C++, Linux system programming, and device driver concepts.

## Features
- Interactive Terminal Menu
- CPU Information (Completed)
- Memory Information (Completed)
- Disk Information (Completed)
- Process Information (Completed)
- Network Information (Completed)
- System Uptime (Completed)
- System Report Generation (Completed)
- Driver Status Demonstration (Completed)

## Technologies
- **C++ (C++11 or higher)**
- **Linux System APIs**
- **Makefile**
- **Git**

## How to Build and Run
This project is designed for **Linux** environments.

### Compilation
Use the provided Makefile:
```bash
make
```

### Execution
Run the compiled binary:
```bash
make run
# OR
./bin/system_monitor
```
